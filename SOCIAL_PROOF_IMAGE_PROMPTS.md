## 🛠️ WORKFLOW DE GENERACIÓN

### Paso 1: Generar Imágenes
```bash
# Para cada prompt:
1. Copia el prompt completo
2. Pégalo en tu generador preferido (DALL·E 3, Midjourney, etc.)
3. Genera 2-3 variantes
4. Selecciona la mejor
```

### Paso 2: Descargar y Optimizar
```bash
# Convertir a WebP (Linux/Mac):
cwebp -q 85 imagen-original.jpg -o nombre-archivo-1200w.webp

# Crear versión mobile (800x800):
cwebp -resize 800 800 -q 85 imagen-original.jpg -o nombre-archivo-800w.webp
```

### Paso 3: Subir al Servidor
```bash
# Estructura de carpetas:
/assets/images/social-proof/
  ├── reviews/
  │   ├── google-review-emergency-service-1200w.webp
  │   ├── google-review-leak-repair-1200w.webp
  │   └── google-review-installation-1200w.webp
  ├── team/
  │   ├── team-plumbers-group-los-mochis-1200w.webp
  │   ├── senior-plumber-service-van-1200w.webp
  │   └── plumber-workshop-tools-1200w.webp
  └── before-after/
      ├── before-after-pipe-leak-repair-1200w.webp
```

## 📊 CHECKLIST DE CALIDAD

Antes de publicar, verifica:

- [ ] **Tamaño correcto:** 1200x800px para desktop
- [ ] **Formato WebP:** Compresión 80-85%
- [ ] **Alt text descriptivo:** SEO-optimizado
- [ ] **Lazy loading:** `loading="lazy"` en todas las imágenes
- [ ] **Responsive:** Versión 800x800 para mobile
- [ ] **Consistencia visual:** Todas las imágenes tienen estilo similar
- [ ] **Sin watermarks:** Imágenes limpias sin marcas de agua
- [ ] **Texto legible:** En screenshots de Google Reviews
- [ ] **Realismo:** Fotos profesionales pero auténticas
- [ ] **Contexto local:** Ambiente mexicano/Los Mochis visible

## 🎨 GUÍA DE ESTILO VISUAL

### Paleta de Colores (mantener consistencia):
- **Azul corporativo:** #0066cc, #0284c7
- **Verde éxito:** #22c55e (CTAs, testimonios positivos)
- **Blanco limpio:** #ffffff (backgrounds)
- **Grises neutros:** #64748b, #1e293b (textos)

### Filtros Recomendados (Post-procesamiento):
- Temperatura: +5% (cálido)
- Saturación: -10% (profesional, no artificial)
- Contraste: +10% (claridad)

### Elementos a Evitar:
- ❌ Stock photos genéricas (se nota)
- ❌ Iluminación artificial/estudio (poco auténtico)
- ❌ Modelos de publicidad (buscar realismo)
- ❌ Logos/textos visibles de competencia
- ❌ Fechas/timestamps futuros en reviews

---

## 💡 TIPS PARA MEJORES RESULTADOS

1. **Para Screenshots de Google**: Usa DALL·E 3, es el mejor en texto legible
2. **Para Fotos de Personas**: Midjourney v6 con `--style raw` da resultados más realistas
3. **Para Before/After**: Asegura que el "after" sea visualmente más atractivo
4. **Consistencia de Iluminación**: Todas las fotos de equipo deben tener iluminación similar
5. **Negative Prompts** (Stable Diffusion): "cartoon, illustration, 3d render, fake, staged, stock photo"
